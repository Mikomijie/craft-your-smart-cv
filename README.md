# CraftCV — Smarter Resumes

**Your CV, but smarter.**

CraftCV is an AI-powered CV builder that helps you create, tailor, and download professional CVs in minutes. Chat naturally with AI to build your CV from scratch, then tailor it perfectly to any job description instantly.

---

## Features

- 💬 **Chat to Build** — Talk naturally, AI extracts and structures your CV automatically  
- 📤 **Upload Existing CV** — Upload your current CV and enhance it with AI  
- 🎯 **AI Job Tailoring** — Paste any job description and get a perfectly tailored CV in seconds  
- 📊 **Match Score** — See how well your CV matches the job with skill gap analysis  
- 💌 **Cover Letter Generator** — Get a tailored cover letter with tone options  
- 📄 **3 PDF Templates** — Modern, Classic, and Minimal designs  
- 🔐 **Auth & Save** — Sign up to save multiple CVs and access them anytime
